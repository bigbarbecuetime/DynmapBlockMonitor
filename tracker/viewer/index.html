Load tracker data

Drop chunks.csv and players.csv anywhere on this page, or pick them below. If you are serving this folder over HTTP, Load from server reads them straight from ../data and enables live follow.

Opened straight from disk (file://) the browser will not let the page read the folder, so use the file pickers. Serve the tracker folder to get live mode: python viewer/serve.py
